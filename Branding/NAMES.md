# App name candidates

A native iPhone / iPad / Mac client for the JS8 weak-signal digital mode
(8-tone FSK, Costas-array sync, keyboard-to-keyboard chat, store-and-forward
relays, heartbeats), driven through a Digirig Lite and radios like the QMX
or FTDX3000.

## The "JS8Call" problem

**JS8Call** is the name of the existing desktop program by Jordan Sherer
(KN4CRD). Calling the iPhone app "JS8Call" would make it look like an official
port and would collide with the desktop program in every search, forum thread
and support question. **JS8** on its own is the name of the mode, and ham apps
routinely use mode names descriptively (FT8 apps, PSK31 apps). The safest
pattern is a brand name of its own plus a descriptive App Store subtitle:

> **Eightfold** · JS8 messaging for iPhone, iPad & Mac

That way App Store search for "JS8" still finds it (subtitle and keywords are
indexed), and the brand is not borrowed.

## 1. Descriptive (clear, low risk, less memorable)

| Name | Rationale |
|---|---|
| **Pocket JS8** | Says what it is: the whole JS8 station in your pocket. Easy to find in search. |
| **JS8 Go** | Short and portable-sounding; fits POTA/SOTA field use with a QMX. |
| **JS8 Console** | Matches the app's dark radio-console look; reads like a piece of station gear. |
| **JS8 Field** | Built for the field: Digirig, battery, a QRP rig and a phone. |
| **JS8 Link** | Hints at relays and store-and-forward linking, a core JS8 feature. |
| **JS8 Messenger** | Plain-English for non-hams who see it over your shoulder; JS8 is a messaging mode. |
| **JS8 Mobile** | The most literal option; searchable, but the most generic of the lot. |

## 2. Evocative / brandable (stronger identity, needs a subtitle)

| Name | Rationale |
|---|---|
| **Eightfold** | JS8 is 8-tone FSK; the name holds the "8" without the "JS". Feels calm and deliberate, like the slow mode itself. |
| **Undernoise** | JS8 decodes signals around −24 dB SNR, well under the audible noise floor. The name is the mode's superpower. |
| **Costas** | JS8 frames start with a 7×7 Costas array (`4 2 5 6 1 3 0`) for sync. An insider's name with a strong graphic built in. |
| **Tonestep** | The staircase of 8 FSK tones is what a JS8 signal looks like on a waterfall. |
| **Faintline** | A faint line on the waterfall that turns into a conversation. |
| **Noisefloor** | Where JS8 lives. Slightly technical; reads as a place. |
| **Skywave** | HF propagation via the ionosphere. Lovely word, but crowded (see search notes). |
| **Driftline** | Waterfall traces drift down the screen; also the slow, unhurried pace of JS8 QSOs. |
| **Lowband** | Low power, low bandwidth, low SNR. Understated and confident. |
| **Octave** | Eight tones, eight notes. Clashes with GNU Octave; listed for completeness. |
| **Waterline** | Waterfall plus the line between noise and signal. |
| **Quietwave** | The mode is slow and quiet, but it gets through. |

## 3. Ham-culture puns (fun, best for the ham audience)

| Name | Rationale |
|---|---|
| **Ragchew** | Ham slang for a long friendly QSO, which is exactly what JS8 chat is. **Taken** on the App Store (NetLogger companion, 2026). |
| **QTC** | The Q-code for "I have messages for you"; JS8 is store-and-forward messaging. Short, but cryptic to newcomers. |
| **QRV8** | "QRV" = ready to operate, plus the 8. Compact and punny, hard to say aloud. |
| **CQ Pocket** | Calling CQ from your pocket. Friendly and obvious to hams. |
| **Heartbeat** | JS8's `@HB` beacons tell the network you're on the air. Very generic as a brand. |
| **Elmer8** | An "Elmer" is a ham mentor. Cute, but implies a teaching app. |
| **Barefoot** | Ham slang for running without an amplifier, like a 5 W QMX. Charming, but says nothing about JS8. |
| **Seventy3** | "73" means best regards. Warm sign-off; spelled-out numbers look awkward on a home screen. |

> Avoid **"88"** puns. "88" is ham shorthand for love and kisses, but it is also a
> well-known extremist code and will be misread outside the hobby.

## Quick conflict search (top 8)

Web search on 2026-10-23. This is not a trademark search; run a USPTO / App
Store Connect name check before committing.

| Name | What turned up | Risk |
|---|---|---|
| **Eightfold** | No App Store ham/radio app by that name. **Eightfold AI** is a large enterprise HR/"talent intelligence" software company with web and mobile clients, so the word is in use for software, in an unrelated market. An App Store name like "Eightfold JS8" or "Eightfold Radio" sidesteps an exact clash. | Medium |
| **Undernoise** | Nothing found under "Undernoise" or "Below Noise"; only unrelated noise-meter apps. | Low |
| **Costas** | No app by that name. The only hit was HamChat (Morse/PSK decoder), which mentions a Costas *loop* in its description. | Low |
| **Tonestep** | Nothing. Near misses are step counters (TinySteps, ToeSteps) and a guitar-pedal app (TONEX / AIRSTEP). | Low |
| **Pocket JS8** | No app named Pocket JS8 / JS8 Pocket / JS8 Mobile. No native iOS JS8 client turned up at all; the closest things are `js8d` (headless daemon with a web UI) and On-Air Net Scraper (net tool that mentions JS8Call). Good news for the project. | Low (but leans on "JS8") |
| **Skywave** | **Global Skywave** is an App Store app for radio operators (operator map, messaging, alerts), and there's an Android "Skywave Radio Schedules". | High |
| **Ragchew** | **RagChew** by Tim Morgan is on the App Store (NetLogger net-following companion, released 2026). | Taken |
| **QTC** | No app named QTC. Note that **Radio Messenger** (messages over radio via TNC/audio modem) exists on iOS; avoid "Messenger" as the main word. | Low name risk, weak brand |

---

## Ranked top 5

1. **Eightfold**: short, sayable, ownable; the 8 ties straight to JS8 and 8-FSK
   without borrowing the JS8Call brand. Gives the best icon (a glowing figure-8).
2. **Undernoise**: the most meaningful name; tells the JS8 story in one word.
   Cleanest search result of the lot.
3. **Costas**: niche but delightful for hams who know the mode; its icon (the
   7×7 sync grid) is the most graphic and reads best at 60 px.
4. **Tonestep**: friendly and visual; the staircase icon *is* a JS8 signal.
5. **Pocket JS8**: the safe descriptive fallback if a brand name feels like too
   much; great for search, weak as a brand.

## Recommendation

Go with **Eightfold**, listed on the App Store as
**"Eightfold: JS8 Messenger"** (subtitle: *Weak-signal HF chat for iPhone, iPad
& Mac*). It keeps "JS8" where people search for it, does not pass the app off as
JS8Call, and the figure-8 icon sits naturally next to the dark console UI.

If the Eightfold AI overlap worries you, **Undernoise** is the runner-up with
no conflicts found and an equally strong story.

Logo concepts for all five are in `logos/` (SVG) and `icons/` (1024 px PNG);
open `index.html` to compare them side by side.
